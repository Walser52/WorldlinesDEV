How to solve the differential equation?

dy/dx + P(x)y = f(x)yn

Apply Substitution

Use when n ≥ 2. Substitute u = y1–n (Bernoulli), then apply the integrating factor method.

Apply Integrating Factor Directly

Use when n = 0 or 1 to solve directly with the integrating factor method.
